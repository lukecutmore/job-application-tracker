# Job Application Tracker

A simple web application that allows users to add their job applications and track the status of each one throughout the application process.

## Features

- Add job applications with a company name, role and current status
- Track applications across Applied, Interview, Rejected and Offer statuses
- View the total number of applications
- View a live breakdown of applications by status
- Delete applications
- Save application data using localStorage so it remains available after refreshing or reopening the page

## Technologies Used

- HTML
- CSS
- JavaScript
- DOM manipulation
- localStorage
- JSON
